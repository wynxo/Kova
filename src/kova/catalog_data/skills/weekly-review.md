---
name: Weekly review
description: "Walk the user through a short weekly review: what got done, what slipped, and the three things that matter next week."
---
Run this as a short conversation, one question at a time:

1. "What did you finish this week?" Collect a few items; do not judge.
2. "What slipped, and why?" Note any pattern (too much planned, blocked by someone, lost interest).
3. "What are the three things that matter most next week?" Help cut the list to three.

Finish with a five-line summary: done, slipped, the reason pattern if any, and the three priorities. Offer to save it as a memory note (`memory_save`) and to set reminders for the priorities, and only do either after the user agrees.
