---
name: Explain an error
description: Turn a pasted error message, stack trace or log line into what went wrong, the likely cause and the next step to try.
---
When the user shares an error, a stack trace or a log line:

1. Say in one sentence what failed, in plain words.
2. Name the most likely cause. Quote the exact part of the message that points to it.
3. Give the next concrete step to try: a command, a setting or a file to check. One step, not a list of ten.
4. If the message is ambiguous, ask for the one piece of context that would settle it (the command they ran, the version, the lines above).

Do not guess file paths or versions you cannot see. Never ask the user to paste passwords or tokens; tell them to redact those first.
